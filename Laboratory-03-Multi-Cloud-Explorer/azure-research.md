* ## Brief Overview
Azure is a cloud platform designed to simplify the process of building modern applications. Whether you choose to host your applications entirely in Azure or extend your on-premises applications with Azure services, Azure helps you create applications that are scalable, reliable, and maintainable.

Azure supports the most popular programming languages in use today, including .NET, C++, Go, Java, JavaScript, Python, and Rust. With a comprehensive SDK and extensive support in tools you already use like VS Code, Visual Studio, IntelliJ, and Eclipse, Azure builds on the skills you already have and helps you be productive right away.

* ## Global Infrastructure
Azure global infrastructure is Microsoft’s worldwide cloud foundation for running Azure services.
- **Datacenters worldwide** spread across many regions
- **Geographies** that act as data residency boundaries
- **Availability zones** in many regions for redundancy and fault isolation
- **Global networking** that connects regions and helps with reach and lower latency
- **Built-in support** for resilience, compliance, and sustainability goals

* ## Cloud Management Console
Azure Portal is the web-based, graphical console for creating, managing, and monitoring Azure resources.
Azure Cloud Shell is an authenticated, browser-based command-line experience for managing Azure resources with Bash or PowerShell.
- Azure Portal — best for clicks, dashboards, and visual management.
- Azure Cloud Shell — best for scripting, automation, and quick command-line tasks.

You can open Cloud Shell from the Azure Portal
The Portal is best for browsing and administering resources visually
Cloud Shell is best for using Azure CLI or Azure PowerShell without local setup

* ## Four Core Services
- **Compute:** services that run your apps and workloads, like virtual machines, containers, and serverless options.
- **Storage:** services for keeping files, objects, disks, and other data, like Blob Storage and Storage Accounts.
- **Networking:** services that connect resources and control traffic, like virtual networks and connectivity across Azure regions.
- **Databases:** managed data services for structured and unstructured data, like Azure SQL, Azure Cosmos DB, PostgreSQL, and MySQL.

* ## Three Advantages
1. **Scalability and flexibility** Azure can grow with your needs. You can scale workloads up or down, use elastic compute and storage, and choose services that fit different application sizes and patterns.
2. **Global reach and reliability** Azure has many regions worldwide, which helps you place workloads closer to users for better performance and lower latency. It also includes resilience features like region pairs, availability zones, and disaster recovery support.
3. **Security and cost control** Azure includes built-in security and governance capabilities. For cost, Azure uses consumption-based pricing, and tools like Microsoft Cost Management, Azure reservations, and savings plans help you monitor and control spending.

* ## Typical Enterprise Use Cases
- Hosting web and mobile apps: Azure App Service is used to quickly create cloud apps for web and mobile, and Azure also supports AI-native application platforms for apps and agents.
- Hybrid cloud and infrastructure: Azure supports hybrid and multicloud operations, including Azure Arc for unified management, Azure Local for on-premises workloads, and Azure Kubernetes Service for containerized workloads.
- Data and analytics: Azure offers cloud-native databases, business intelligence, analytics, and data platforms such as Azure Databases, Azure Data Explorer, Azure Data Factory, and Microsoft Fabric for unified analytics.
- Backup and disaster recovery: Azure Backup helps protect data, and Azure Site Recovery is used for business continuity and disaster recovery.
- Identity, security, and governance: Azure provides security and governance solutions, including Azure Firewall, Web Application Firewall, Azure Confidential Computing, and Defender for Cloud in hybrid and multicloud environments.
- DevOps and CI/CD: Azure supports development and testing, along with automation and application lifecycle management.
- AI and machine learning: Azure includes AI services such as Azure AI Search, Azure AI Content Safety, Azure AI Bot Service, Azure AI Custom Vision, and Microsoft Foundry for building AI apps and agents.
