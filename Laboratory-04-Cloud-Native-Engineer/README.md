## Docker Commands Executed

### 1. Checkpoint 3 commands used

1. Check if Docker is installed and its version: docker --version
2. Check Docker service status (systemd): sudo systemctl status docker
3. Check if Docker daemon is running: sudo systemctl is-active docker
4. Check Docker info (detailed system-wide info: containers, images, storage driver, etc.): docker info
5. List running containers: docker ps
6. List all containers (including stopped ones): docker ps -a
